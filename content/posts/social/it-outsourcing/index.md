国内 IT 外包大致分三类：**纯人力外包**按人天/人月结算、派驻驻场，是大厂补编制的主要来源；**项目外包**按总价包干，承包方承担全流程交付风险；**离岸外包**服务海外客户，靠人力成本差做远程研发与测试。

三类之外，地域也很关键——同一类外包在不同城市由不同厂商主导。下表按「外包类型 × 梯队/区域」列出代表公司及其核心侧重。

| 外包类型 | 梯队/布局范围 | 代表公司 | 核心特点与侧重 |
| --- | --- | --- | --- |
| **纯人力外包（驻场人力型）** | 全国头部（北上广深全覆盖） | 法本信息、软通动力、中软国际 | 按人天/人月结算，大规模派驻技术人员驻场；覆盖互联网、通信、金融、政企全行业，是大厂补编制的核心供应商 |
|  | 北京区域主力 | 京北方、外企德科 | 京北方侧重银行后台人力+BPO；外企德科主打高端IT灵活用工，外资客户居多 |
|  | 上海区域主力 | 微创软件 | 微软合资背景，外资企业IT驻场需求占比高 |
|  | 广深区域主力 | 易宝软件 | 深圳本土老牌厂商，聚焦互联网、通信行业驻场外包 |
| **项目外包（交付型）** | 全国头部（北上广深全覆盖） | 中电金信、博彦科技 | 项目总价包干，承担全流程交付风险；中电金信为金融IT项目龙头，博彦科技覆盖多行业综合交付 |
|  | 北京区域主力 | 中科软、神州信息 | 中科软为保险IT项目绝对龙头，核心系统市占率超60%；神州信息侧重银行核心系统+政务大数据项目 |
|  | 上海区域主力 | 汉得信息、新致软件 | 汉得信息为ERP实施外包龙头，深耕SAP/Oracle生态；新致软件侧重华东保险、银行IT项目 |
|  | 广深区域主力 | 赛意信息、润和软件 | 赛意信息主打华南制造业ERP与工业数字化项目；润和软件侧重金融科技与鸿蒙生态项目交付 |
| **离岸外包（跨境研发型）** | 北上广深均设交付/对接中心 | 博彦科技、华钦科技、瞬联软件、微创软件 | 服务海外客户，依托人力成本差提供远程研发/测试；博彦科技综合体量最大，华钦科技聚焦金融离岸，瞬联软件侧重通信/汽车嵌入式高端离岸，微创软件依托微软资源主打欧美软件企业外包 |
